# Personal Homepage

Personal homepage built with Hugo.

## Setup

1. Install Hugo (Extended version):
   ```bash
   brew install hugo
   # or
   npm install -g hugo-extended
   ```

2. Run development server:
   ```bash
   hugo server
   ```

3. Build for production:
   ```bash
   hugo
   ```

## Structure

- `content/` - Markdown content files
- `themes/personal/` - Custom theme
- `hugo.toml` - Configuration file

## Deployment

The `public/` directory contains the generated static site. Deploy this to GitHub Pages or any static hosting service.
